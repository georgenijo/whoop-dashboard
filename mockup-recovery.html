VII. Method·NOTE 07 / MT 007 / 008

How this page was assembled.

01.

Capture →

Whoop 4.0 strap worn 24 / 7. HRV and RHR sampled during the deepest 90 minutes of slow-wave sleep on each consecutive night.

02.

Score →

Whoop's proprietary recovery index combines HRV, RHR, sleep performance, and respiratory rate into a single 0—100 percentage.

03.

Classify →

Each morning is sorted into green (≥67), yellow (34—66), or red (<34). Cutoffs follow Whoop's own thresholds; no smoothing applied.

04.

Render

Plotted as inline SVG, set in Inter Tight + Playfair Display + JetBrains Mono. No JavaScript libraries. Fin.
