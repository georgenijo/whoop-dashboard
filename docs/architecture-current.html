Application and data flow

Next.js web + API

Web pages and the iOS API share the same authenticated routes, tenant-scoped DB layer, integrations vault, logs, plans, and Coach threads.

Health sources

Whoop OAuth sync and signed webhooks write health data. The iOS app uploads HealthKit workouts and heart-rate streams.

Coach providers

Anthropic runs through the SDK. Cursor runs through cursor-agent and the bundled scoped MCP server on opti.

SQLite

One WAL database is canonical. Health-domain reads are user-scoped except the retained maintainer journal, whose tenant migration is deferred; live backups use SQLite’s online backup API.

Deployment

scripts/deploy uses Fleet, builds on opti with Node 20.20.2, switches an immutable release symlink, restarts user services, and verifies the build SHA.

CI and retired infrastructure

GitHub Actions is CI only. The Oracle VM, nginx, Streamlit app, and Python sync services are retired and are not in the production request path.

Operator boundary

Use scripts/deploy and fleet exec opti; do not address a production IP directly. Provisioning, migration, backup, rollback, and Oracle-retirement procedures live in the environment and deployment guide.
